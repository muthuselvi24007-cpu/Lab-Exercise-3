# Lab-Exercise-3
# Aim:
To evaluate the usability and user experience of an existing website or mobile application using heuristic principles, compare it with 2–3 competing applications, and identify and implement the required UX improvements.

# Algorithm:

Select an existing website or mobile application for evaluation.
Select 2–3 competing websites or applications for comparison.
Study the interfaces based on usability heuristics such as visibility, consistency, error prevention, and user control.
Identify usability problems and compare the UX of the selected applications.
Prioritize the identified issues based on their severity and impact on users.
Design and incorporate the required changes to improve usability and user experience.
Evaluate the improved design to verify that the identified problems have been reduced.

# Output:
The output consists of a heuristic evaluation and comparison of 2–3 competing applications/websites, along with the redesigned screens showing the implemented UX improvements.
